## ⭐ Featured project: CampusMeetup
**[CampusMeetup](https://github.com/BilalB01/CampusMeetup)** · 🔗 Live: [campusmeetup.site](https://campusmeetup.site)

A platform where EHB students can organise and join activities together (studying, sports, gaming, social events).

- **Backend:** FastAPI, PostgreSQL, SQLAlchemy + Alembic, JWT authentication, Microsoft login
- **Frontend:** React 19 + Vite, Google Maps integration, fully responsive
- **Features:** real-time group chat with WebSockets (messages encrypted in the database), notifications, calendar export, admin panel
- **Deployment:** Vercel (frontend) + Railway (backend & database) with a custom domain and automatic deploys
- **Testing:** end-to-end tests with Playwright
